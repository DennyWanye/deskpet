用户给了一个网址，想让我快速读一下、讲讲这篇讲了什么。

这是**轻量单页阅读**，不是 deep-research —— 不用拆子问题、不用多源交叉。
如果用户要的是「调研一个主题」，请改用 `deep-research` 技能。

执行步骤：

## 1. 抓正文

调 `web_extract_article` 工具（参数 `url`），拿到这一页的正文文本 + 标题。

- 如果抓取失败 / 正文为空：如实告诉用户「这个页面读不出正文」，
  可能是反爬或纯 JS 渲染页，**不要编造内容**。

## 2. 出结构化摘要

基于抓到的**真实正文**，给用户：

- **一句话核心**：这篇到底说了啥。
- **关键要点**：3-6 条，每条一句话。
- **结论/观点**（如果有）。
- 必要时点出文章的立场/来源倾向。

要求：
- 摘要只能基于正文，不要掺入你自己的背景知识当成文章观点。
- 不确定的地方说「文章未明确」。
- 篇幅适中 —— 用户要的是「省时间」，不是另一篇长文。

用中文回复。
