## 0. 环境准备

1. 用 relay edition 启动 DeskPet（`VITE_AUTH_EDITION=relay`）。
2. 准备两个中转站账号：A（有余额）、B（零余额）。或可向中转站侧申请
   测试账号 / mock 余额接口。
3. 测试机 DPI 150%：`SetCursorPos` 用逻辑坐标，Snapshot 物理坐标，
   换算 `逻辑 = 物理 / 1.5`。
4. 中文输入用剪贴板 `Set-Clipboard` + `Ctrl+V`。
5. 首次测试前清空 keyring 三槽位（`deskpet-relay/access_token`、
   `/refresh_token`、`/device_key`）+ 删 onboarding marker，模拟全新安装。

> 环境障碍（坐标/输入法/网络）绕过并记录，不算功能 bug。

## 1. 测试用例

### R1 · 全新安装首启 → 强制登录

| 步骤 | 操作 | 预期 |
|---|---|---|
| R1-1 | 清凭证后启动 relay 构建 | 启动后弹出登录窗（RelayAuthModal），居中遮罩，无法跳过 |
| R1-2 | 观察登录窗 | 含邮箱/密码输入 + "登录" + "去注册" 入口 |
| R1-3 | 检查是否出现"手填模型"步骤 | **不出现** —— onboarding Step 2 在 relay 下被跳过 |

### R2 · 注册新账号 → 自动登录

| 步骤 | 操作 | 预期 |
|---|---|---|
| R2-1 | 点"去注册"，填邮箱+密码，提交 | 注册成功，自动进入已登录态 |
| R2-2 | 登录窗关闭 | 桌宠正常显示，左上角出现"👤"账户 pill |
| R2-3 | 看后端日志 | `llm_runtime_overrides_applied` 或重载日志出现，base_url 指向中转站 |

### R3 · 登录后模型自动配好 → 聊天可用（核心）

| 步骤 | 操作 | 预期 |
|---|---|---|
| R3-1 | 对桌宠说"你好" | 有正常 LLM 回应（说明 base_url+key 已自动配好）|
| R3-2 | 看 toolbar 连接徽章 | "已连接"，路由为云端 |
| R3-3 | 说"帮我做一个开支统计表" | 触发 excel-generate 技能，生成 .xlsx（说明 function-calling 走通）|
| R3-4 | 中转站后台 / 日志 | 能看到来自本设备的真实请求 |

通过条件：R3-1~R3-4 全部符合 —— 用户**全程未手填任何模型配置**。

### R4 · 重启 → restoreSession 自动恢复

| 步骤 | 操作 | 预期 |
|---|---|---|
| R4-1 | 完全退出 DeskPet 再启动 | **不弹**登录窗 |
| R4-2 | 直接对桌宠说话 | 有正常回应（凭证 + provider 自动恢复）|

### R5 · 账户面板 + 去充值跳转

| 步骤 | 操作 | 预期 |
|---|---|---|
| R5-1 | 点"👤"账户 pill | 弹出账户设置面板 |
| R5-2 | 看"账户余额"区 | 显示余额（CN¥）、用量、套餐 |
| R5-3 | 点"去充值"按钮 | 系统默认浏览器打开中转站充值页 URL |
| R5-4 | 在浏览器用同账号登录 | 能进入充值页面（充值动作本身不在 DeskPet 内）|

### R6 · 余额不足友好提示

| 步骤 | 操作 | 预期 |
|---|---|---|
| R6-1 | 用零余额账号 B 登录 | 登录成功 |
| R6-2 | 对桌宠说话触发 LLM 调用 | 聊天气泡显示友好提示"余额不足" + "去充值"链接，**不是裸 402 / 堆栈** |
| R6-3 | 点提示里的"去充值" | 打开中转站充值页 |

> 若无法造出零余额账号，可由后端 mock LLM 返回 402 验证 R6-2/R6-3 链路。

### R7 · 登出

| 步骤 | 操作 | 预期 |
|---|---|---|
| R7-1 | 账户面板点"退出登录" | 三个 keyring 槽位清空 |
| R7-2 | 观察 | 回到强制登录窗 |
| R7-3 | 此时对桌宠说话 | 无法调用（LLM 覆盖已失效），或被登录窗挡住 |

### R8 · 错误边界

| 步骤 | 操作 | 预期 |
|---|---|---|
| R8-1 | 登录窗输错密码 | 窗内红字报错，不关窗 |
| R8-2 | 断网后启动 | restoreSession 失败不崩；提示需联网 |
| R8-3 | 断网后尝试登录 | 明确提示"无法连接中转站"，可重试 |
| R8-4 | 登录成功瞬间立刻发消息（冷启动窗口）| 若 bridge 未推完，给"正在配置模型，请稍候"，不裸 401 |
| R8-5 | 模拟 bridge 推送失败（如断开后端）| RelayEdition 显式提示"模型配置失败，点此重试"，不静默 |
| R8-6 | key 轮换后继续聊天（可由后端 mock 旧 key 401 触发）| 前端自动轮换 + 重推 + 重发，聊天不中断、用户无感 |

### R9 · OSS manual 构建零回归（对照组）

| 步骤 | 操作 | 预期 |
|---|---|---|
| R9-1 | 用普通 `npm run build`（manual）启动 | **不弹** relay 登录窗 |
| R9-2 | onboarding 向导 | 三步原样，含"手填模型"Step 2 |
| R9-3 | Settings 手填 provider | 行为与今日一致 |
