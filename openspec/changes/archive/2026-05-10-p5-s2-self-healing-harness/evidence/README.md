# Evidence — P5-S2

每个 phase 完成后必须在这里放一份 evidence 文档，证明实际跑过、观测过、符合预期。

格式：`<task-id>-<slug>.md`

每份 evidence 至少包含：

1. **场景**：测的是哪个 case（用 plain English 说，不是引用 spec）
2. **操作步骤**：能让别人重现的 step-by-step
3. **抓到的 log / 截图**：粘贴关键日志行（脱敏 secret）和截图
4. **结论**：相对预期，跑出了什么差异，是否通过

无 evidence 的 phase 不算闭环，不能划掉 tasks.md 里的 phase 验收 task。
