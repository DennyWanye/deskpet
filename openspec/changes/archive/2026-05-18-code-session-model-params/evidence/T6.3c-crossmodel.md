# T6.3c — cross-model + UX refinements (2026-05-19)

Addresses two user follow-ups after T6.3b:

1. "你试了哪些模型？" — T6.3b only fully verified gpt-5.5; claude was
   UI-caps only. Now verified **cross-model end-to-end on the running
   stack**.
2. "推理模式应该是单选" — Thinking/Fast were two independent toggles
   (could both be on). They are conceptually exclusive (high reasoning
   /slow vs low latency) → converted to a single-select segmented
   "推理模式" (默认 | Thinking | Fast), caps-gated.

## Changes

- `ChangeModelModal.tsx`: Thinking+Fast toggles → single-select
  `推理模式` segmented (default/thinking/fast, mutually exclusive,
  only the modes the model supports are offered). Dead `Toggle`
  component + styles removed.
- `llm/resolution.py` `_attach_code_params`: now model-aware — strips
  `reasoning_effort` for entries whose model family does not expose it
  (Anthropic/Gemini/DeepSeek…), using the same `model_param_caps` the
  picker uses. So a Claude request never carries a meaningless
  `reasoning_effort` (the mapper still derives one from `thinking`,
  but it's an OpenAI-ism).
- `test_code_session_resolution_params.py`: contract updated — opus
  model strips reasoning_effort; added a gpt case that keeps it.
