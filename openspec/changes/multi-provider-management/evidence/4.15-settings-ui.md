## Wire-format contract (locked by tests)

Outbound (frontend → backend):
- `settings_providers_list_request`
- `settings_providers_add { id, name, base_url, model, api_key, enabled }`
- `settings_providers_update { id, patch }` — `patch.api_key` omitted when blank
- `settings_providers_remove { id }`
- `settings_providers_reorder { ordered_ids }`

Inbound (backend → frontend, dispatched to `useProvidersStore`):
- `settings_providers_list_response { providers }`
- `providers_changed { providers }`
- `settings_providers_reordered { providers }`
- `settings_providers_added { provider }`
- `settings_providers_updated { provider }`
- `settings_providers_removed { id }`
- `settings_providers_error { reason, detail }`

These match `specs/frontend-ipc-surface/spec.md` exactly.
