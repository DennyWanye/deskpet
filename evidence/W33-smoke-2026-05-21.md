  restoreSession refresh-on-startup) covers the contract; a true

## Process hygiene

Same pattern as `W3-smoke-2026-05-21.md` — before each launch:

```powershell
Get-Process deskpet,deskpet-backend -ErrorAction SilentlyContinue | Stop-Process -Force
Get-NetTCPConnection -LocalPort 8100 -ErrorAction SilentlyContinue |
  Where-Object State -eq 'Listen' |
  ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

This session: no zombie processes blocked startup (clean launch first try).
