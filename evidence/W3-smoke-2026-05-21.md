## Process hygiene reminder

The "启动失败" dialog at step 3 is a recurring environmental issue
documented in `~/.claude/projects/G--projects-deskpet/memory/MEMORY.md`:
`TaskStop` doesn't reliably reap orphan Python backend processes on
Windows. Before any future smoke test, run:

```powershell
Get-Process deskpet -ErrorAction SilentlyContinue | Stop-Process -Force
Get-NetTCPConnection -LocalPort 8100 -ErrorAction SilentlyContinue |
  Where-Object State -eq 'Listen' |
  ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```
