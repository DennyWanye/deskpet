## 1. 安装时需要较大的磁盘空间

### 现象

- 内测版安装包本身约 **5.4 GB**。
- 安装过程中 Windows 还会在 **C 盘**额外占用约 **5.4 GB** 的临时/缓存空间
  （即使你把 DeskPet 装到非 C 盘也一样）。
- 加上其他临时文件，**安装时 C 盘建议预留约 7 GB 可用空间**。
- C 盘空间不足时，安装会中途弹「磁盘空间不足 / Out of Disk Space」并失败。

### 为什么

这是 Windows Installer 的固定行为：安装 MSI 时，安装包数据会被复制一份缓存到
`C:\Windows\Installer\`（供将来卸载/修复用），这部分缓存无法重定向到其他盘。

### 规避方法

- 安装前确认 **C 盘有至少 7 GB 可用空间**。
- 如果 C 盘紧张，可以先清理：清空回收站、清理 Windows 临时文件、卸载不常用的
  大型软件，腾出空间后再安装。
- 安装完成后，那部分临时空间会释放，长期占用主要是程序本体。

> 我们正在评估把大型 AI 模型从安装包里移出、改成首次启动时按需下载，
> 这能把安装包和磁盘需求大幅降低。这是内测期会推进的改进。

## 2. 首次安装时出现 SmartScreen 安全警告

### 现象

双击安装包时，Windows Defender SmartScreen 弹出一个蓝色窗口：
**「Windows 已保护你的电脑 — Microsoft Defender SmartScreen 已阻止启动一个
未识别的应用程序」**。

### 为什么

内测版的安装包**尚未完成代码签名**。SmartScreen 对没有签名（或签名信誉还没
建立）的程序一律弹这个警告——这**不代表 DeskPet 有病毒**，只代表 Windows
还「不认识」这个发布者。

### 规避方法

1. 在蓝色窗口里，点击 **「更多信息」** 链接。
2. 窗口会展开，出现一个 **「仍要运行」** 按钮。
3. 点击 **「仍要运行」**，即可正常继续安装。

> 我们正在办理代码签名证书。正式发布版本签名后，这个警告就会消失。
> 内测期请按上面的步骤放心继续。

## 3. 启动时会弹出一个黑色命令行窗口

### 现象

启动 DeskPet 后，除了桌宠窗口本身，桌面上还会**同时出现一个黑色的命令行
（cmd）窗口**，里面滚动着一些英文日志。

⚠️ **重要**：**不要关闭这个黑窗口**——它其实是 DeskPet 的后台服务，关掉它会
导致桌宠的功能（聊天、语音等）直接掉线。

### 规避方法

- **不要关它**。如果觉得它碍眼，可以把它**最小化**（点窗口左上角图标 → 最小化），
  让它待在任务栏里即可。
- 这个窗口会和 DeskPet 一起退出——你正常退出 DeskPet 时它会自动关闭。

> 注：此问题的修复（让后台服务不再弹窗）已在代码层面完成，会在后续重新打包的
> 内测版本里生效。如果你拿到的版本仍弹窗，说明它是修复前的构建。
